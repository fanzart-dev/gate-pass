Only the AWB / Origin / Destination text is printed — no borders, logo or footer, so it lands in the blank space on your existing sticker sheet. Each value sits in a 1.6cm (h) × 9.5cm (w) box starting 60mm from the left, and the font size automatically responds to the number of letters — shrinking for longer text so it always fits inside that box.
