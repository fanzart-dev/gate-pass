{% if current_user.is_admin %}
Restarting the numbering

Enter the custom prefix or starting format (e.g. FZ- or FZ27-) and set the next starting number. Resetting will start new gate passes from your exact specified format (e.g. FZ-00001). Typing a whole example such as FZ-00001 sets both at once.

A prefix that has been used before is fine — the count carries on from the last number issued under it rather than going back to 00001, so {{ settings.serial_prefix }} would continue at {{ next_serial }}. A number that has already been issued cannot be handed out again: the register refuses it, and the screen will tell you the first free one. Nothing is deleted — every pass already issued keeps its number and stays in the register.
