Everything it needs is passed in; `with context` at the import site gives it url_for and settings. #} {# One card = one printed page of one gate pass. A long invoice prints as several pages, all carrying the SAME serial number — it is one gate pass, not two, so the number is never suffixed or split. #} {% macro pass_card(gate_pass, page_items, page_no, page_total) %}

Gate Pass

{# Labels sit in fixed-width spans so the colons line up down the block. The colon is OUTSIDE the span deliberately: inside it, it would follow the label text and move with its length, which is the thing being fixed. #}

{# The date the pass was ISSUED, off the record — not today's date at render time. A pass is a document: reprinting FZ-00027 next year must produce the same sheet it produced the day it was raised, and `datetime.now()` would quietly restamp it. For a pass being printed as it is issued, which is the normal case, this IS today. #}
Issue Date: {{ gate_pass.issued_at|as_day_month_year }}
{% if page_total > 1 %}
Page {{ page_no }} of {{ page_total }}
{% endif %}
From :
{{ gate_pass.supplier_name }}		 Customer :
{{ gate_pass.customer_name }}
{# "Document No", not "Invoice No": a pass is raised against a tax invoice OR a stock transfer memo, and a memo has a TO number rather than an invoice number. One neutral label covers both. Date sits under it so the whole provenance of the pass — which document, and when — reads as one block. #} {# Prints whatever was typed on the review screen, and stays empty when nothing was — so the box is still there to be written in by hand at the gate. Never parsed from the invoice: a remark is a note about the consignment, and no invoice carries one. #}
Document No: {{ gate_pass.invoice_no }}
Date: {{ gate_pass.invoice_date }}
Remarks : {% if gate_pass.remarks %}{{ gate_pass.remarks | line_breaks }}{% endif %}
{# The row height is written in here rather than left to the layout to work out. A flex-stretched table re-divides its rows whenever the printable page height changes — a different paper size, margins or a "fit to page" setting — which is what made the same pass print with tall warped rows on one machine and correct ones on another. #} {% set rows = page_rows(page_items|length) %} {# Every budgeted row is drawn, so the ruled box and its column dividers run the full height of the item area exactly like the printed form. Only the rows carrying an item get `item-row`, and only that class draws a horizontal rule — the blank rows below keep the vertical dividers and nothing else. `rows` is the height budget: it divides ITEM_BODY_MM into --row-h above, so a 3-item pass gets roomy 6.27mm rows and a full 26-item pass tightens to 5.30mm and still fits on the sheet. Sl No. runs straight through the pass: page 2 of a 32-item pass starts at 27, not back at 1. #} {% for r in range(1, rows + 1) %} {% set entry = page_items[r - 1] if r - 1 < page_items|length else None %} {% endfor %}
Sl No. Item Name Quantity No.of Cartons
{{ entry[0] if entry else '' }} {{ entry[1].item_name if entry else '' }} {{ entry[1].quantity if entry else '' }} {{ entry[1].cartons if entry else '' }}

{# Who generated the pass is a record, not a signature — hence no rule above it, and the quiet styling. #}

{% endif %} {% if settings.show_vehicle == '1' %}
Vehicle : {{ gate_pass.vehicle_no }}
{% endif %}
